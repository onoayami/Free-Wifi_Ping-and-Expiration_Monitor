# Wi-Fi Monitor (Free Wi-Fi Connection Checker)

macOSのメニューバーに常駐し、**フリーWi-Fiの時間制限**や**通信状態**をスマートに見守るツールです。
カフェやコワーキングスペースなどで「いきなりWi-Fiが切れて作業内容が消えてしまった…」というトラブルを防ぐため、時間切れ前に通知を行います。

---

## ✨ 主な機能

### ⏱️ フリーWi-Fi 接続切れアラーム
カフェなどの「◯分で自動切断されるWi-Fi」対策機能です。
接続からの時間を計測し、指定した時間（例: 50分・55分）に通知を出して作業の保存を促します。
未登録のWi-Fiに接続した際は「何分後にアラームを鳴らしますか？」と自動でポップアップが出るため、設定忘れもありません（通知時間はカンマ区切りで複数設定可能）。

### 💤 スマートなスリープ（離席）復帰
トイレ休憩や電話などでMacを閉じた場合でも、**15分以内に同じWi-Fiに復帰**した場合は、前回のタイマー（接続時間）をそのまま継続してバックグラウンドで計測を続けます。
15分以上経過してから復帰した場合は自動で完全リセットされ、カウントが0から再スタートします。

### 🏠 「非通知Wi-Fi」の登録（自宅・職場など）
時間制限がない安全なWi-Fi（ご自宅やオフィスなど）をリストに登録しておけば、そこに接続した際はタイマーや通知が自動でOFFになります。
一度登録するだけで、現在の環境を自動判別して動作します。

### 📊 3つの表示モード（クリックで切替）
メニューバーの項目「【表示内容】」をクリックすることで、表示させたい情報を瞬時に切り替えられます。

- **⏳ ネット接続時間**：現在のWi-Fiに接続してからの経過時間（例: `🌐 48分12秒`）
- **📶 ネット速度**：Ping応答速度と通信状態をリアルタイム表示（例: `🔵 23ms` / `🔴 オフライン`）
- **⏱️ タイマー残り時間**：後述のカスタムタイマー使用時のカウントダウン表示

### 🍅 カスタムタイマー（作業用・ポモドーロ対応）
ネットワークの接続状態とは完全に独立して使えるタイマー機能です。
「ポモドーロ」や「作業」など任意の名前をつけて起動でき、メニューバーでカウントダウンを確認可能。終了後はワンクリックで「同じ時間でリピート再開」ができます。

### 🔐 VPN接続ステータス確認
現在VPNを使用しているかどうか、および接続中のサービス名（例: NordVPN, ExpressVPN 等）をメニュー内に表示できます（「⚙️ その他」設定から表示のON/OFFが可能）。

## 🖥 動作環境

- macOS（Apple Silicon / Intel どちらも可）
- Python 3.9 以上

---

## 📦 セットアップ

```bash
# 仮想環境を作成して有効化
python3 -m venv .venv
source .venv/bin/activate

# 必要なパッケージをインストール (rumps, pyobjc等)
pip install rumps pyobjc
```

---

## 🚀 起動方法

```bash
python "FreeWifi Connection Checker.py"
```

起動すると、画面右上のメニューバーにアイコンが表示されます。
（※ 初回起動時、現在接続しているWi-Fiの名前(SSID)を正確に取得するために、macOSから**位置情報の利用許可**を求められる場合があります。許可すると正しいWi-Fi名が表示されるようになります）

アプリを終了させる場合は、メニューの一番下にある **Quit** をクリックするか、起動したターミナルで `Ctrl + C` を押してください。

---

## 📂 設定データについて

非通知Wi-Fiの設定や、アプリの状態を保存するファイルは以下の場所に自動生成されます。
- `~/.wifimonitor_safe_ssids.json` （非通知Wi-Fiリスト）
- `~/.wifimonitor_settings.json` （VPN表示などの設定）
- `~/.wifimonitor.log` （トラブルシューティング用ログ記録）
