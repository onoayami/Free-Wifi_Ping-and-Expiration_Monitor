# Free Wi-Fi Ping & Expiration Monitor

macOS のメニューバーに常駐し、**フリー Wi-Fi の接続状態・通信速度・接続時間**を見守る軽量ツールです。
カフェや図書館などの「◯分まで」という時間制限つき Wi-Fi で、**時間切れ前に通知**してくれます。

> [rumps](https://github.com/jaredks/rumps) を使った Python 製のメニューバーアプリです。

---

## 🎯 主な機能

### 1. メニューバー表示（3モード切替）
クリックで表示内容を切り替えられます。

| モード | 表示例 | 説明 |
|--------|--------|------|
| 📶 ネット速度 | `🔵 23ms` | Google DNS への ping 応答速度（🔵速い / 🟡普通 / 🟠遅い / 🔴切断） |
| ⏳ ネット接続時間 | `🌐 48分12秒` | Wi-Fi に接続してからの経過時間 |
| ⏱️ タイマー残り時間 | `🌐 14:58` | 後述のカスタムタイマーの残り時間 |

### 2. フリー Wi-Fi 接続切れアラーム
接続から指定した時間（デフォルト **50分・55分**）が経過すると、**作業保存を促すポップアップ**で警告します。
時間制限つきフリー Wi-Fi が切れる前に気づけます。

- 通知タイミングは複数設定可能（例: `50, 55`）
- カンマ区切りで自由に指定、`0` でオフ

### 3. アラーム非通知 Wi-Fi（自宅・職場など）
自宅や職場の Wi-Fi を**非通知リスト**に登録しておくと、その回線ではアラームが鳴りません。
登録すると自動的にネット速度表示に切り替わります。

### 4. カスタムタイマー（ポモドーロ等）
Wi-Fi とは独立した汎用タイマーです。

- 任意の**タイマー名**（例: ポモドーロ）と分数を設定
- メニューバーに残り時間を `mm:ss` でカウントダウン表示
- 起動中にメニューを開くと「かけ直す / 時間を再設定 / オフにする」を選択可能
- 終了時はポップアップで通知（同じ時間で再設定も可）

### 5. スリープ復帰・瞬断への配慮
- 一時的な瞬断（約20秒以内）はオフライン扱いにせず誤判定を防止
- スリープから **5分以内**の復帰なら、同じ Wi-Fi のタイマーを引き継ぎ

## 🖥 動作環境

- macOS（Apple Silicon / Intel）
- Python 3.9 以上

---

## 📦 セットアップ

```bash
# 仮想環境を作成して有効化
python3 -m venv .venv
source .venv/bin/activate

# 依存パッケージをインストール
pip install rumps pyobjc
```

---

## 🚀 起動方法

```bash
python "FreeWifi Connection Checker.py"
```

起動すると画面右上のメニューバーにアイコンが表示されます。
終了はメニューの **Quit**、またはターミナルで `Ctrl + C`。

> 初回起動時、SSID（接続先 Wi-Fi 名）を正確に取得するために
> **位置情報の許可**を求められる場合があります。許可すると接続先名が表示されます。

## ⚙️ 仕組み（ざっくり）

- **5秒ごと**に Apple / Google の接続確認用 URL へアクセスし、実際にインターネットへ出られているかを判定
- SSID は CoreWLAN → `ipconfig` → `system_profiler` の順で取得（位置情報権限がなくても極力取得）
- 表示更新は **1秒ごと**、変化があった項目だけを再描画して軽量に動作
